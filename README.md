# Nestar Demo

Next.js 14.2.1, React 18, TypeScript, and ESLint using the Pages Router.

```sh
yarn install
yarn dev
```

Open http://localhost:3000. Edit `pages/index.tsx` for the home page.
Global styles live in `styles/globals.css`, and API routes in `pages/api/`.

No App Router, Tailwind CSS, src directory, or import alias is configured.

Checks: `yarn lint`, `yarn tsc --noEmit`, and `yarn build`.
